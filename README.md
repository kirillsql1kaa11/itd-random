# 🕵️ ИТД: Угадай Автора (Викторина по постам)

Веб-приложение в минималистичной тёмной эстетике социальной сети [ИТД](https://xn--d1ah4a.com/). Игроки отгадывают популярных авторов по скриншотам постов, соревнуются в общем рейтинге, предлагают свои посты и авторов.

---

## ✨ Что нового и как всё устроено

### 1. 🏠 Главный экран (Лобби)
- **Ввод никнейма**: поле для ввода игрового ника (автоматически сохраняется в памяти браузера).
- **Выбор режима игры**:
  - **Блиц 10** — 10 постов с начислением очков и множителем за скорость ответа.
  - **Выживание** — 3 жизни (индикаторы-сердца), игра на рекорд серии до первой критической ошибки.
  - **Свободный** — спокойное прохождение без таймера и жизней.
- **Быстрые действия на главной**:
  - **«Предложить пост»**: модальное окно с загрузкой скриншота (Drag & Drop, выбор файла или вставка через `Ctrl + V`), выбором автора из базы и цитатой. Пост отправляется в очередь модерации.
  - **«Авторы ИТД»**: каталог авторов с живым поиском по имени, `@handle` или стилю, а также кнопкой «+ Предложить нового автора».
  - **«Рейтинг игроков»**: таблица рекордов лидеров по набранным очкам.

---

### 2. 🎮 Игровой процесс и верстка викторины
- **Строго 4 автора в вариантах**: алгоритм гарантирует ровно **1 правильный ответ** и **3 уникальных автора-дистрактора** из базы (все варианты перемешиваются).
- **Чистый векторный дизайн без лишних эмодзи**: все смайлики заменены на лаконичные векторные SVG-иконки в стиле интерфейса ИТД (сердца жизней, галочки верификации, лупы, кнопки действий).
- **Зум скриншота**: клик по карточке поста или клавиша `Z` открывает изображение во весь экран.
- **Горячие клавиши**:
  - `1`, `2`, `3`, `4` — выбор варианта ответа
  - `Space` — следующий пост
  - `H` — подсказка
  - `Z` — полноразмерный зум
- **Звуковые эффекты**: синтезированные через Web Audio API звуки ответов и победных серий с переключателем звука в шапке.

---

### 3. 🌐 Облачная база данных (Supabase)
В проект включен скрипт интеграции с **Supabase** (`js/supabase.js`) и готовая схема базы данных:
- Файл схемы: `supabase_schema.sql` (таблицы: `authors`, `posts`, `leaderboard`, `suggestions_posts`, `suggestions_authors`).
- **Как подключить свой Supabase (по желанию)**:
  1. Создайте бесплатный проект на [supabase.com](https://supabase.com/).
  2. В разделе **SQL Editor** вставьте и выполните код из файла `supabase_schema.sql`.
  3. Откройте панель управления (кнопка в самом низу сайта) и введите ваш **Project URL** и **Anon API Key**.
- **Офлайн / Локальный режим**: если ключи Supabase не заданы, игра автоматически и без ошибок работает через **IndexedDB**, сохраняя рекорды и посты локально.

### 4. 🚀 Развертывание на хостинг (Vercel)
Проект полностью готов для хостинга на **Vercel**:
- Добавлен файл конфигурации `vercel.json` с чистыми URL и заголовками безопасности.
- Проект инициализирован как чистый Git-репозиторий.

**Инструкция по деплою на Vercel**:
1. Создайте репозиторий на GitHub и отправьте код:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/itd-quiz.git
   git push -u origin master
   ```
2. Откройте [vercel.com](https://vercel.com/), нажмите **Add New Project** и выберите ваш репозиторий.
3. Нажмите **Deploy** — через 5 секунд сайт будет доступен по всему миру с бесплатным SSL-сертификатом!

### 5. ⚙️ Панель администратора
- По просьбе, админка убрана из верхней навигации и доступна **только по аккуратной ссылке в самом низу страницы (в футере)**: `Панель управления`.
- **PIN-код по умолчанию**: `1234` (или `admin`).
- Возможности:
  - Загрузка скриншотов постов (включая `Ctrl + V`).
  - **Холст замазывания ника**: рисование тёмной плашки или размытия прямо поверх имени автора на скриншоте перед добавлением в игру.
  - Управление списком авторов и вопросов.
  - Настройка ключей Supabase.
  - Экспорт и импорт базы в JSON.
