# ИТД — Кто автор?

Викторина по постам соцсети ИТД: смотришь на скриншот и угадываешь, кто из авторов его написал — по стилю, шуткам и вайбу.

**[Играть → itd-random.vercel.app](https://itd-random.vercel.app)**

## Режимы

| Режим | Как играется |
| --- | --- |
| **Блиц 10** | 10 постов на очки, 15 секунд на ответ: решает скорость |
| **Выживание** | 50 раундов с 3 жизнями: ошибки выбивают из игры |
| **Свободный** | 100 раундов без таймера и штрафов — разминка и тренировка |

## Что есть в игре

- **Рейтинг игроков** — таблица лучших скроллеров ИТД с фильтром по режимам.
- **Авторы ИТД** — каталог авторов с поиском.
- **Личная статистика** — история ваших игр и лучшие результаты.
- **Карточка результата** — итог раунда можно сохранить и скинуть друзьям.
- **Предложить пост или автора** — отправка на модерацию прямо из интерфейса.
- **Ставится на телефон** — открываешь в браузере и добавляешь на главный экран.

Аккаунт не нужен: придумываешь никнейм в один клик (или доверяешь генератору случайных) — и играешь.
