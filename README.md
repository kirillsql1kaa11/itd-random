# 🕵️ ИТД: Угадай Автора (Викторина по постам)

Веб-приложение в стилистике и эстетике социальной сети [ИТД](https://xn--d1ah4a.com/), в котором игроки отгадывают, кто из популярных авторов написал тот или иной пост по скриншоту.

---

## ✨ Основные возможности

### 🎮 Режим игрока (Викторина)
- **3 режима игры**:
  - **Блиц 10**: 10 случайных постов из базы с подсчетом очков, бонусом за скорость и итоговым званием (от *Новокека* до *Легенды ИТД*).
  - **Выживание**: игра до 3 ошибок с накоплением рекордной серии (*Streak*).
  - **Свободный**: спокойная тренировка без таймера.
- **Интерактивный зум (Lightbox)**: клик по скриншоту или клавиша `Z` открывает полноразмерный просмотр скриншота, чтобы разглядеть мелкий текст и детали поста.
- **Горячие клавиши**:
  - `1`, `2`, `3`, `4` — выбор вариантов ответа
  - `Space` / `Enter` — переход к следующему вопросу
  - `H` — подсказка
  - `Z` — зум скриншота
- **Звуковые эффекты**: синтезированные через Web Audio API звуки кликов, победной серии, правильных и ошибочных ответов (с кнопкой выключения 🔊 / 🔇).
- **Карточка автора**: при ответе раскрывается профиль автора с его стилем, описанием и ссылкой на ИТД.
- **Конфетти и анимации**: динамические визуальные эффекты при победных сериях.

---

### ⚙️ Панель администратора (Админка)
- **Защита входом**: PIN-код по умолчанию: `1234` (или `admin`).
- **Загрузка скриншотов**:
  - Перетаскивание файлов (Drag & Drop) или выбор через проводник.
  - **Вставка из буфера обмена (`Ctrl + V`)**: сделайте скриншот поста на [итд.com](https://xn--d1ah4a.com/) (например, через `Win + Shift + S`) и просто нажмите `Ctrl + V` в админке!
- **Встроенный инструмент замазывания ника (Censor Tool)**:
  - Если на скриншоте виден ник или аватарка автора, вы можете прямо в админке мышкой наложить аккуратную тёмную плашку или размытие перед сохранением.
  - Есть кнопка отмены действий (`Undo`).
- **Управление авторами**:
  - Выбор правильного автора из выпадающего списка популярных авторов ИТД.
  - Создание нового автора прямо из формы или через отдельное модальное окно.
- **Управление базой постов**:
  - Список всех добавленных постов с миниатюрами.
  - Кнопка **Тестировать вопрос** (🎯), редактирование (✏️) и удаление (🗑️).
  - **Экспорт и импорт базы в JSON**: сохранение всех вопросов и скриншотов в один резервный файл.
  - Кнопка быстрого восстановления стартового пака постов.

### 🎨 Дизайн и эстетика
- Строгий минимализм и чистая тёмная тема в духе ИТД (`#08080a`, `#121216`, `#16161a`).

## 🚀 Запуск проекта

### Вариант 1 (Рекомендуемый: локальный сервер на Python)
В папке проекта уже есть скрипт `serve.py`. Запустите его командой:

```bash
python serve.py
```

Сервер запустится по адресу: **http://localhost:3000** и автоматически откроет страницу в вашем браузере.

### Вариант 2 (Прямой запуск)
Вы можете просто открыть файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari). Все данные сохраняются в браузере в **IndexedDB** без ограничений по размеру скриншотов.

## 📁 Структура проекта

```
itd-random/
├── index.html          # Главная страница (разметка, модалки, панель игры и админки)
├── serve.py            # Локальный веб-сервер на стандартной библиотеке Python
├── README.md           # Документация проекта
├── css/
│   └── style.css       # Стили тёмной темы ИТД, анимации, адаптив
└── js/
    ├── sound.js        # Синтезатор звуковых эффектов (Web Audio API)
    ├── db.js           # Хранилище IndexedDB (скриншоты, посты, авторы, бэкап)
    ├── authors.js      # База популярных авторов ИТД и генерация вариантов
    ├── presets.js      # Стартовый пак аутентичных постов и генератор карточек
    ├── game.js         # Движок викторины, подсчет очков, серия, таймер, хоткеи
    ├── admin.js        # Логика админки (загрузка, Ctrl+V, замазывание ника)
    └── app.js          # Инициализация приложения, навигация, тосты
```
